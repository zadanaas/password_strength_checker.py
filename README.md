# 🔐 Password Strength Checker

A simple Python script that evaluates password strength based on cybersecurity best practices.  
It checks for:
- Minimum length (8 characters)
- Uppercase and lowercase letters
- Numbers
- Special symbols
- Optional: common breached password detection

   cd password_strength_checker
   python password_strength_checker.py
